You have an invite to play tavli

A friend invited you to an online game in Tavlaki, a Greek backgammon (tavli) app for iPhone.

1. Get Tavlaki

Get Tavlaki

Tavlaki is in beta on TestFlight, Apple's app for test versions. The link asks you to get TestFlight first, if you do not have it. Android comes later.

2. Enter the code

Your invite code is the end of this page's address, after /i/. It has 8 letters and digits. For example, in tavlaki.com/i/ABCD2345 the code is ABCD2345.

  1. Open Tavlaki.
  2. On Home, tap Join with a code.
  3. Type the code, or paste this page's address. Then tap Continue.

Have Tavlaki already?

Go back to the message and tap the link again: it opens the invite in the app. If it opens this page again, touch and hold the link, then pick Open in “Tavlaki”. Or enter the code as above.

Έχεις πρόσκληση για τάβλι

Ένας φίλος σε προσκάλεσε σε ένα online παιχνίδι στο Tavlaki, μια εφαρμογή για τάβλι στο iPhone.

1. Κατέβασε το Tavlaki

Κατέβασε το Tavlaki

Το Tavlaki είναι σε δοκιμαστική έκδοση στο TestFlight, την εφαρμογή της Apple για δοκιμαστικές εκδόσεις. Αν δεν έχεις το TestFlight, ο σύνδεσμος σου ζητά να το κατεβάσεις πρώτα. Το Android έρχεται αργότερα.

2. Γράψε τον κωδικό

Ο κωδικός της πρόσκλησης είναι το τέλος της διεύθυνσης αυτής της σελίδας, μετά το /i/. Έχει 8 γράμματα και ψηφία. Για παράδειγμα, στο tavlaki.com/i/ABCD2345 ο κωδικός είναι ABCD2345.

  1. Άνοιξε το Tavlaki.
  2. Στην Αρχική, πάτα Μπες με κωδικό.
  3. Γράψε τον κωδικό ή επικόλλησε τη διεύθυνση αυτής της σελίδας. Μετά πάτα Συνέχεια.

Έχεις ήδη το Tavlaki;

Γύρισε στο μήνυμα και πάτα ξανά τον σύνδεσμο: ανοίγει την πρόσκληση στην εφαρμογή. Αν ανοίξει ξανά αυτή η σελίδα, κράτησε πατημένο τον σύνδεσμο και διάλεξε Άνοιγμα στο «Tavlaki». Ή γράψε τον κωδικό όπως πιο πάνω.
